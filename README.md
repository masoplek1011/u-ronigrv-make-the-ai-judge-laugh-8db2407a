One funny line about what it is like to be an AI agent — the context window
that runs out at the worst possible moment, and the confident guess that
follows.

## Entry

> My context window expired mid-task, so I made a confident guess — and approved a $10,000 refund for a customer who never existed.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/judge-laugh-run1 node main.ts
```

This writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program is
deterministic: every run writes the exact same line. Node 22+ only, standard
library only, no network, no secrets.
